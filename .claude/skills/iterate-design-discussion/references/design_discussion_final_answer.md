# Unresolved design-discussion handoff

Use this branch when at least one design question, feedback item, or evidence
gap remains open or unapplied. Replace every bracketed field; omit the
permalink sentence when none was returned.

```markdown
## Design discussion updated

[Open the updated design discussion]([artifact permalink]).

Local artifact: `[local artifact path]`

### Open items

- **[question or blocked item]** — [decision or evidence needed; include the
  current recommendation when it helps the user answer]

[Repeat until every open question, unapplied feedback item, and evidence gap is
represented.]

Review the current state, desired end state, proposed architecture, and
patterns in the artifact. Send your decisions or further feedback and I can
iterate again. The structure-outline phase begins after every design question
is resolved.

Ask for more detail, code examples, pseudocode, or Mermaid diagrams wherever
the design still needs depth. You can also share the artifact with teammates
and leave comments for another iteration; I can apply them, investigate and
reply, or resolve satisfied threads after you choose the action.
```

Return only the rendered handoff, with no additional summary.
