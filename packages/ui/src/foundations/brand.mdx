# Deck Club brand

**Index cards and highlighters.** Pastel highlighter ink on lilac-tinted index-card
paper. Light mode only, by decision. The source of truth is `brand/README.md`; the
tokens live in `src/styles/theme.css`.

Pastels are always fills. Text on them is Ink, which keeps every pairing above
WCAG 2.2 AA. Spend boldness once per screen.
